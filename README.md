# lecture_transcriber

강의 녹음을 Whisper로 전사하고, 강의 슬라이드와 용어집을 바탕으로 Claude Code가 교정해 **검색과 복습에 쓰기 좋은 Markdown 전사본**을 만드는 로컬 도구입니다. 듣는 과목을 직접 추가해 쓸 수 있습니다.

## 주요 기능

- **로컬 전사:** faster-whisper large-v3로 내 PC의 GPU에서 전사합니다.
- **과목별 관리:** 과목마다 용어집, 교정 사전, 표기 규칙을 따로 쌓습니다.
- **전사 품질 보정:** 환각 문구와 누락 구간을 찾아 해당 구간만 다시 전사합니다.
- **슬라이드 연동:** 강의자료를 등록하면 문맥 교정과 슬라이드 위치 표시에 사용합니다.
- **일괄 처리:** 대기열, 이어서 처리, 긴 녹음의 분할 파일(`_01`, `_02`)을 지원합니다.
- **로컬 웹 화면:** `127.0.0.1`에서만 열리며 외부에서는 접속할 수 없습니다.

## 필요 환경

- Windows, NVIDIA GPU (메모리 8GB 권장)
- Python 3.14, [ffmpeg](https://ffmpeg.org)
- 문맥 교정을 쓰려면 [Claude Code](https://claude.com/claude-code)

## 설치

```powershell
git clone <이 저장소 주소>
cd lecture_transcriber
winget install Gyan.FFmpeg
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

첫 실행 때 Whisper 모델(약 3GB)과 OCR 모델을 내려받습니다.

## 시작하기

1. `run.bat`을 실행하면 브라우저에서 `http://127.0.0.1:8765`가 열립니다.
2. **과목 관리 → ＋ 과목 추가**에서 과목 이름과 강의 유형을 고릅니다.
3. 만들어진 `강의자료` 폴더에 슬라이드(PDF, PPTX)를 넣습니다.
4. 녹음 파일 이름을 `과목이름_YYMMDD.m4a`로 맞춰 **전사** 화면에 올립니다.
5. 전사가 끝나면 이 폴더를 VS Code로 열고 Claude Code에 화면에 나온 `/correct <작업이름>`을 입력합니다.

| 강의 유형 | 어울리는 수업 |
|---|---|
| 한국어 강의 | 슬라이드와 수업이 대부분 한국어 |
| 영어 용어를 많이 쓰는 강의 | 한국어로 수업하지만 용어와 슬라이드는 영어 |
| 코드 실습 강의 | 변수명, 함수명을 코드 표기대로 유지 |
| 판서·손필기 강의 | 슬라이드 없이 손필기 PDF를 자료로 사용 |

유형은 시작 규칙일 뿐이며, 과목 관리 화면에서 언제든 수정할 수 있습니다.

## 폴더 구조

기본 강의 폴더는 `문서\Lectures`이고, 과목을 추가할 때 다른 곳을 지정할 수 있습니다.

```text
Lectures/
├─ 기말고사_녹음본/           일괄 처리할 녹음
├─ 중간고사_녹음본/           용어집을 시작할 샘플 녹음 (선택)
└─ <과목>/
   └─ Finals_Scope/
      ├─ 강의자료/            슬라이드, 참고 자료
      └─ 전사본/              최종 교정본 (.md)
```

과목 데이터(`data/`), 작업 파일(`jobs/`), 녹음과 결과물은 내 PC에만 저장되며 `.gitignore`로 저장소에서 제외됩니다.

## Claude Code 명령

| 명령 | 하는 일 |
|---|---|
| `/register-slides <과목>` | 강의자료를 읽어 페이지 인덱스 등록 |
| `/bootstrap-glossary <과목>` | 기존 자료로 용어집 시작 |
| `/correct <작업이름>` | 전사본 문맥 교정 |
| `/recorrect <과목>` | 용어집 변경 후 다시 교정 |
| `/crosscheck <작업이름> <md 경로>` | 다른 전사본과 대조 |

자세한 동작은 [CLAUDE.md](CLAUDE.md)에 있습니다.

## 주의
